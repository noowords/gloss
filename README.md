# Endpoints

### Аутентификация `/auth`

| Метод  | Путь               | Описание                        | Статус |
| ------ | ------------------ | ------------------------------- | ------ |
| `POST` | `/register`        | Регистрация нового пользователя | 🟡     |
| `POST` | `/login`           | Вход (получить JWT токен)       | 🔴     |
| `POST` | `/logout`          | Выход (инвалидировать токен)    | 🔴     |
| `POST` | `/refresh`         | Обновить JWT токен              | 🔴     |
| `POST` | `/forgot-password` | Запрос на сброс пароля          | 🔴     |
| `POST` | `/reset-password`  | Сброс пароля по токену          | 🔴     |
| `GET`  | `/me`              | Получить текущего пользователя  | 🔴     |

### Пользователи `/users`

| Метод    | Путь            | Описание                      | Статус |
| -------- | --------------- | ----------------------------- | ------ |
| `GET`    | `/`             | Получить всех пользователей   | 🟢     |
| `GET`    | `/{id}`         | Получить пользователя по ID   | 🟢     |
| `GET`    | `/{id}/profile` | Получить профиль пользователя | 🟢     |
| `PUT`    | `/{id}`         | Обновить пользователя         | 🔴     |
| `PATCH`  | `/{id}/role`    | Изменить роль пользователя    | 🔴     |
| `DELETE` | `/{id}`         | Удалить пользователя          | 🔴     |

### Профили `/profiles`

| Метод | Путь    | Описание               | Статус |
| ----- | ------- | ---------------------- | ------ |
| `GET` | `/me`   | Получить свой профиль  | 🔴     |
| `GET` | `/{id}` | Получить профиль по ID | 🔴     |
| `PUT` | `/me`   | Обновить свой профиль  | 🔴     |
| `PUT` | `/{id}` | Обновить профиль       | 🔴     |
