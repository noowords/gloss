# Gloss API

Монорепозиторий бэкенд-системы, спроектированный по принципам Чистой Архитектуры (Clean Architecture), паттерна CQRS и вертикальных срезов (Vertical Slices).

## 🚀 Запуск приложения

Для запуска HTTP API сервера в режиме оптимизации (`release`), выполните следующую команду из корня репозитория:

```bash
cargo run -p http-api --release
```
