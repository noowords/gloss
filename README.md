# Gloss API

Монорепозиторий бэкенд-системы, спроектированный по принципам Чистой Архитектуры (Clean Architecture), паттерна CQRS и вертикальных срезов (Vertical Slices).

## Настройка окружения

Перед запуском приложения убедитесь, что в вашей системе установлены следующие инструменты:
- [Docker & Docker Desktop](https://docker.com)
- [Rust & Cargo](https://rust-lang.org)
- [just](https://github.com)

Перед запуском приложения создайте файл `.env` в корне проекта на основе шаблона `.env.example` и заполните его своими локальными данными (настройки базы данных MySQL, порты и параметры подключения API):

```bash
cp .env.example .env
```

*Примечание: При локальном запуске убедитесь, что база данных MySQL запущена и доступна по адресу, указанному в вашем `.env`.*

### Основные команды (Docker)

* `just run` — Запустить сервисы окружения разработки (по умолчанию) с автоперезапуском кода.
* `just run dev` — Запустить сервисы окружения разработки с автоперезапуском кода.
* `just run release` — Запустить продакшен-сервер в изолированном фоновом режиме.
* `just build` — Собрать Docker-образы для окружения разработки (по умолчанию).
* `just build dev` — Собрать Docker-образы для окружения разработки.
* `just build release` — Собрать релизные Docker-образы для продакшена.
* `just restart` — Быстро перезапустить контейнеры разработки (по умолчанию).
* `just restart dev` — Быстро перезапустить контейнеры окружения разработки.
* `just restart release` — Быстро перезапустить боевые контейнеры продакшена.
* `just stop` — Полностью остановить контейнеры разработки и очистить сеть (по умолчанию).
* `just stop dev` — Полностью остановить контейнеры окружения разработки и очистить сеть.
* `just stop release` — Полностью остановить продакшен-окружение.
* `just logs` — Посмотреть живые логи запущенных контейнеров разработки в реальном времени.
* `just ps` — Проверить статус, порты и состояние запущенных процессов.
