# Gloss API

Монорепозиторий бэкенд-системы, спроектированный по принципам Чистой Архитектуры (Clean Architecture), паттерна CQRS и вертикальных срезов (Vertical Slices).

## Настройка окружения

Перед запуском приложения убедитесь, что в вашей системе установлены следующие инструменты:
- [Docker & Docker Desktop](https://docker.com)
- [Rust & Cargo](https://rust-lang.org)
- [just](https://github.com)

Перед запуском приложения создайте файл `.env` в корне проекта на основе шаблона `.env.example` и заполните его своими локальными данными (настройки базы данных MySQL, порты и параметры подключения API):

```bash
cp .env.example .env
```

*Примечание: При локальном запуске убедитесь, что база данных MySQL запущена и доступна по адресу, указанному в вашем `.env`.*

## Запуск приложения

Вся инфраструктура и рутинные задачи разработки полностью контейнеризированы и управляются через короткие команды `just`. Больше не нужно вводить длинные команды `docker compose` или `cargo` вручную.

* `just dev` — Запустить все сервисы окружения разработки с автоперезапуском кода.
* `just dev build` — Пересобрать Docker-образы для окружения разработки.
* `just dev restart` — Быстро перезапустить контейнеры окружения разработки.
* `just dev down` — Полностью остановить контейнеры окружения разработки и очистить сеть.
* `just prod` — Запустить продакшен-сервер в изолированном фоновом режиме.
* `just prod build` — Пересобрать релизные Docker-образы для продакшена.
* `just prod restart` — Быстро перезапустить продакшен-контейнеры.
* `just prod down` — Полностью остановить продакшен-окружение.
* `just logs` — Посмотреть живые логи запущенных контейнеров в реальном времени.
* `just ps` — Проверить статус, порты и состояние запущенных процессов.
* `just build` — Скомпилировать весь проект локально с помощью cargo.
* `just run` — Запустить проект локально без использования Docker.
* `just fmt` — Автоматически отформатировать весь код с помощью rustfmt.
* `just clippy` — Запустить линтер для поиска потенциальных ошибок и оптимизаций.
* `just test` — Выполнить все тесты в проекте.
* `just clean` — Очистить кэш сборки cargo.
