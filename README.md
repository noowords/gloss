# Gloss API

Монорепозиторий бэкенд-системы, спроектированный по принципам Чистой Архитектуры (Clean Architecture), паттерна CQRS и вертикальных срезов (Vertical Slices).

## Требования

Перед запуском приложения убедитесь, что в вашей системе установлены следующие инструменты:
- [Docker & Docker Desktop](https://docker.com)
- [Rust & Cargo](https://rust-lang.org)
- [just](https://github.com)

## Настройка окружения

Перед запуском приложения создайте файл `.env` в корне проекта на основе шаблона `.env.example` и заполните его своими локальными данными (настройки базы данных MySQL, порты и параметры подключения API):

```bash
cp .env.example .env
```

## Запуск приложения

Вся инфраструктура и рутинные задачи разработки полностью контейнеризированы и управляются через короткие команды `just`. Больше не нужно вводить длинные команды `docker compose` или `cargo` вручную.

### Окружение разработки (с автоперезапуском кода)

Этот режим автоматически поднимает базу данных MySQL и само API с настроенным автоперезапуском (`cargo-watch`) при изменении исходного кода.

* **Запустить все сервисы (логи выводятся в терминал):**
  ```bash
  just dev
  ```
* **Пересобрать Docker-образы (например, после обновления Cargo.toml):**
  ```bash
  just dev build
  ```
* **Быстро перезапустить контейнеры разработки:**
  ```bash
  just dev restart
  ```
* **Полностью остановить контейнеры и очистить окружение:**
  ```bash
  just dev down
  ```

### Мониторинг и диагностика

* **Посмотреть живые логи запущенных контейнеров:**
  ```bash
  just logs
  ```
* **Проверить статус и порты запущенных процессов:**
  ```bash
  just ps
  ```

### Режим оптимизации

Этот режим собирает оптимизированные под релиз образы и запускает проект в изолированном фоновом режиме (контейнеры работают автономно и не блокируют терминал).

* **Запустить продакшен-сервер в фоне:**
  ```bash
  just prod
  ```
* **Пересобрать релизные Docker-образы:**
  ```bash
  just prod build
  ```
* **Перезапустить боевые контейнеры:**
  ```bash
  just prod restart
  ```
* **Полностью остановить продакшен-окружение:**
  ```bash
  just prod down
  ```

## Инструменты качества кода

Вы можете запускать стандартные утилиты проверки кода для всего монорепозитория прямо через `just`:
* `just fmt` — Автоматически отформатировать весь код с помощью rustfmt.
* `just clippy` — Запустить линтер для поиска потенциальных ошибок и оптимизаций.
* `just test` — Выполнить все тесты в проекте.
* `just clean` — Очистить кэш сборки cargo.

*Примечание: При локальном запуске убедитесь, что база данных MySQL запущена и доступна по адресу, указанному в вашем `.env`.*
