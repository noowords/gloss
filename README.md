# Gloss API

Монорепозиторий бэкенд-системы, спроектированный по принципам Чистой Архитектуры (Clean Architecture), паттерна CQRS и вертикальных срезов (Vertical Slices).

## 🛠️ Окружение (Environment)

Перед запуском приложения создайте файл `.env` в корне проекта на основе шаблона `.env.example` и заполните его своими локальными данными (настройки базы данных MySQL, порты и параметры подключения API).

## 🚀 Запуск приложения

Вы можете запускать систему как локально, так и в полностью изолированном Docker-окружении.

### Вариант 1: Запуск через Docker Compose (Рекомендуемый)
Этот способ автоматически поднимет базу данных MySQL и само REST API, настроив сеть между ними:

```bash
# Запуск всех сервисов в фоновом режиме
docker compose up -d

# Пересборка API после изменений в коде (без перезапуска БД)
docker compose up -d --build api

# Полная остановка контейнеров с очисткой временных данных
docker compose down -v
```

### Вариант 2: Локальный запуск (Вручную)
Для запуска HTTP API сервера напрямую на вашем компьютере, выполните следующую команду из корня репозитория:

```bash
cargo run -p http-api
```

Или для запуска в режиме оптимизации:

```bash
cargo run -p http-api --release
```

*Примечание: При локальном запуске убедитесь, что база данных MySQL запущена и доступна по адресу, указанному в вашем `.env`.*
